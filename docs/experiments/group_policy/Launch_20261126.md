Each budget is 1,048,576 sampled decisions or 7,200 cumulative seconds.
Every sampled decision, including filtered groups, counts. Production uses
full Ironclad A10 runs, four policy samples per seed, and the shared milestone
score. See Plan.md for the continuous-score adaptation and differences from PPO.

Validation passed: six objective regressions, real nonzero updates, complete
checkpoints, resume from update 1 to 2, finite model state, unchanged critic
head weights, and four fixed-seed greedy games per algorithm. Each four-game
check completed with zero stuck runs and zero wins. These are interface checks.

The previous owned AlphaDefect PPO process on AutoDL 3090 was saved and stopped.
Existing unrelated primary-server jobs were preserved. Primary resource usage
and PyTorch versions differ across machines, so wall-clock throughput is
hardware-dependent. GRPO uses PyTorch 2.8.0+cu128; DAPO and DSPO use 2.9.0+cu128.
